#  Mobile Sales Dashboard using Power BI

## Project Overview
This project presents an interactive Power BI dashboard to analyze mobile phone sales performance. It provides insights into revenue, sales trends, customer behavior, product performance, and regional sales to support business decision-making.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Quantity Sold
- Monthly Sales Trend
- Brand-wise Sales Analysis
- Model-wise Sales Performance
- Regional Sales Analysis
- Interactive Slicers and Filters

## Business Insights
- Identified top-performing mobile brands.
- Compared monthly sales trends.
- Analyzed regional sales performance.
- Monitored revenue and profit using KPI cards.
- Enabled interactive filtering for better decision-making.
